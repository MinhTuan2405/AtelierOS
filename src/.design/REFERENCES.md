# Design References

Record the useful dimensions of a reference, not only its URL or an instruction
to copy it.

## Repository Architecture

### Reference

The root `README.md`, AtelierOS directory topology, routing diagrams, and command
output from `pnpm design:doctor`.

### What We Like

- Explicit layers and directional flow instead of a loose feature collection.
- Honest command-line language and visible source-of-truth boundaries.
- Replaceable engines contained inside a repository-owned control system.

### What We Do Not Want to Copy

- A literal terminal or IDE imitation as the entire visual identity.
- Dense file trees that require prior knowledge before the value is clear.
- Status output presented as fabricated live telemetry.

### Relevant Design Dimensions

- Composition: routed nodes, rules, and structured system layers.
- Typography: display hierarchy paired with precise monospace annotations.
- Interaction: an actual route composer using real profiles and workflows.
