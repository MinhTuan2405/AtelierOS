# DesignKernel Agent Entry Point

For substantial frontend or design work:

1. Read `src/PRODUCT.md`.
2. Read `src/DESIGN.md`.
3. Read relevant memory under `src/.design/`.
4. Load and follow `atelierOS/kernel/design-director/SKILL.md`.
5. Select the relevant profile and executable workflow.
6. Use installed Taste and Impeccable engines only as routed by that workflow.
7. Do not load unrelated aesthetic skills or arbitrarily blend design systems.
8. Review major UI work with `atelierOS/kernel/design-reviewer/SKILL.md` before completion.
9. Append durable choices to `src/.design/DECISIONS.md`.
10. Never silently overwrite established design language or required behavior.

Use `atelierOS/kernel/constitution/PRIORITY.md` to resolve disagreements. Kernel files are
the source of truth; files generated by `pnpm design:sync` are adapters only.
