# SaaS Product Profile

## Purpose

Task-oriented software interfaces used repeatedly to create, manage, configure,
or collaborate on work.

## Primary Priorities

- clear task flows and information architecture
- predictable navigation and state
- efficient repeated use
- coherent component and token reuse
- accessible feedback and recovery

## Recommended Engine Balance

Impeccable is primary for product structure, shaping, critique, and refinement.
Taste is selective guidance for brand character and avoiding generic surfaces.

## Layout Behavior

Use stable navigation, clear workspace hierarchy, and progressive disclosure.
Favor patterns already established by the product over marketing-style novelty.

## Density

Moderate by default and adjustable where user roles or task frequency demand it.
Use spacing to group meaning, not simply to make the interface feel premium.

## Motion

Motion should explain state transitions, preserve context, and provide feedback.
Keep frequent workflows fast and interruptible.

## Typography Direction

Prioritize legibility, durable hierarchy, and compact UI labels. Brand expression
can appear in headings and empty states without reducing operational clarity.

## Common Risks

- hiding core actions for visual cleanliness
- excessive cards and nested containers
- inconsistent state handling
- decorative dashboard elements in otherwise task-based screens
- a second design system introduced by a new feature

## Review Focus

Review end-to-end tasks, navigation, all states, keyboard use, component reuse,
density, responsive adaptation, and preservation of product behavior.
