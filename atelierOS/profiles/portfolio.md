# Portfolio Profile

## Purpose

Personal, studio, and practice sites that communicate point of view, capability,
and evidence through selected work.

## Primary Priorities

- memorable but authentic identity
- clear authorship, role, and outcomes
- strong project narrative and imagery
- easy contact or next action
- performance and responsive media

## Recommended Engine Balance

Taste usually leads visual concept and narrative. Impeccable shapes content,
navigation, responsive behavior, and finishing.

## Layout Behavior

Let the work determine rhythm. Use a clear index and case-study structure, then
introduce asymmetry or expressive composition where it supports the material.

## Density

Variable by narrative. Give important work room while avoiding empty cinematic
spacing unsupported by content.

## Motion

Motion may express personality and transitions between work, but must not delay
access, hijack scrolling, or hide project details.

## Typography Direction

Distinctive display choices are welcome when paired with readable project text,
captions, credits, and outcomes.

## Common Risks

- style overwhelming evidence and role clarity
- every project using the same mockup template
- oversized type producing unreadable wraps
- slow media and scroll gimmicks
- vague case studies without constraints or outcomes

## Review Focus

Review identity consistency, work comprehension, project narrative, media
quality and performance, responsive composition, accessibility, and contact path.
